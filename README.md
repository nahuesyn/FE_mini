# Deep Sea Portfolio

## 실행
```bash
npm install
npm run dev
```

## Supabase 연결
`.env.example`을 복사해서 `.env`로 만들고 값을 넣으세요.

```env
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

Supabase 테이블은 `supabase.sql`을 실행하면 됩니다.


## 멋사 5·6·7주차 기능 반영
- 5주차: Component, JSX, Props, map() 렌더링 사용
- 6주차: useState, useEffect, useRef 사용
- 7주차: Supabase select / insert / update / delete, .env 구조 사용
